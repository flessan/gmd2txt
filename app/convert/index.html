    Questions people actually ask

    What is a .gmd file?

    A .gmd file is a Geometry Dash level export. It holds the level's data plus its name, creator and song. Tools and mods such as GDShare can import it.

    What is a .txt level string?

    A .txt level string is the raw level text. It usually looks like random letters starting with H4sI… because the game compresses it. It is what tools and modded clients that accept level strings expect, and it is a good plain-text backup of a level.

    Is my file uploaded anywhere?

    No. There is no server in this app. Your files are read and converted inside your browser tab, and they keep working if you go offline.

    Can I convert the other way too?

    Yes. Drop a .txt file (or paste level text) and you get a .gmd file, with the level's name, creator and song filled in automatically when the file contains them.

    I dropped a file and nothing happened.

    Only level files convert: .gmd and .txt. A save file such as CCGameManager.dat is a different thing, and so are images, ZIPs and music files. If your file is a save file, open the advanced workshop instead.

    Why is my .txt file so hard to read?

    That is normal — level strings are compressed. Open Details on a result and choose Readable text to see the decoded version.

    Where did my converted files go?

    Downloads go wherever your browser saves downloads. The app also keeps a private copy of your last conversions in this browser's storage (see Saved in this browser) so you can download them again. Deleting them there does not touch your original files.
